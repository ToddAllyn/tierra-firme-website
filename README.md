# Tierra Firme website

Static site for the Tierra Firme consortium. Hosted on Cloudflare Pages, auto-deploys from `main`.

- Generated by `build.py`: edit content there (and answer pages in `questions_data.py`), then run `python3 build.py` from the repo root.
- Pages: home, `colombia-2027` (Investor Lab 2027, preliminary: 3 days Bogotá, 2 days Medellín, 7 to 12 March), `members`, `the-show`, `questions` (+ `questions/<slug>`), `lanes/<slug>` (one per member lane), `membership` (the only signup), `credits`, `404`.
- Lanes: `LANES` in `build.py`. `cre` (Murphy), `capital` (Shawn), `research` (Todd). Lane pages stay `noindex` with a draft banner until `approved=True`.
- List signup: `functions/subscribe.js` stores `sub:<email>` with `lanes: [...]` (records without `lanes` mean all lanes) and `functions/unsubscribe.js`.
- Photos: `img/bogota/` are Wikimedia Commons photos (credits in `PHOTOS` in `build.py` and on `/credits`). `img/illustrative/` are generated illustrations, always captioned as not the venue.

## Cloudflare Pages settings
- Framework preset: None. Build command: none. Output directory: `/`
- KV binding: `TF_SUBSCRIBERS`
- Env vars: `RESEND_API_KEY` (secret), `UNSUB_SECRET` (secret), `NEWSLETTER_FROM` (e.g. `Tierra Firme <list@tierrafirme.lat>`), `MAILING_ADDRESS`
