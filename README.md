# Tierra Firme website

Static site for the Tierra Firme consortium. Hosted on Cloudflare Pages, auto-deploys from `main`.

- Pages: `index.html`, `members.html`, `the-show.html`, `join.html`, `404.html`
- Generated by `build.py`: edit content there, then run `python3 build.py` from the repo root.
- List signup: `functions/subscribe.js` and `functions/unsubscribe.js`

## Cloudflare Pages settings
- Framework preset: None. Build command: none. Output directory: `/`
- KV binding: `TF_SUBSCRIBERS`
- Env vars: `RESEND_API_KEY` (secret), `UNSUB_SECRET` (secret), `NEWSLETTER_FROM` (e.g. `Tierra Firme <list@tierrafirme.com>`), `MAILING_ADDRESS`
